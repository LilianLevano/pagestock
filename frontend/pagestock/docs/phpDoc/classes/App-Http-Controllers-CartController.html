CartController.php : 17

Winkelmandje van de ingelogde gebruiker.

Het mandje bestaat alleen in de Laravel-sessie (sleutel cart, met per ISBN-nummer het aantal exemplaren); de API kent het niet. Pas bij het reserveren (ReservationController::store()) wordt het naar de API gestuurd.

public api() : PendingRequest

Antwoordt de API met 401 (token verlopen of ongeldig), dan gooit de client een RequestException. Die wordt centraal opgevangen in bootstrap/app.php: de gebruiker wordt uitgelogd en naar /login gestuurd. De controllers hoeven een 401 dus nooit zelf af te handelen.

public index() : View|RedirectResponse

Haalt alle boeken op via GET /books en houdt alleen de boeken uit het mandje over. Boeken die niet meer bestaan (bv. verwijderd door een admin) worden ook uit het mandje in de sessie gehaald, met een melding voor de gebruiker. Anders zouden ze onzichtbaar blijven en zou elke reservatie mislukken met een 404.

Route: GET /cart
