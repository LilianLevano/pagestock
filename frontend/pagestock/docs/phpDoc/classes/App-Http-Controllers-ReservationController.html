ReservationController.php : 16

Reservaties van de ingelogde gebruiker: mandje omzetten naar een reservatie, eigen reservaties bekijken en annuleren, en de afgehaalde boeken tonen.

Alle routes staan achter EnsureApiToken. Een 401 van de API (token verlopen) wordt centraal afgehandeld via Controller::api().

public api() : PendingRequest

Antwoordt de API met 401 (token verlopen of ongeldig), dan gooit de client een RequestException. Die wordt centraal opgevangen in bootstrap/app.php: de gebruiker wordt uitgelogd en naar /login gestuurd. De controllers hoeven een 401 dus nooit zelf af te handelen.
