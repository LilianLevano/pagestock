public api() : PendingRequest

Antwoordt de API met 401 (token verlopen of ongeldig), dan gooit de client een RequestException. Die wordt centraal opgevangen in bootstrap/app.php: de gebruiker wordt uitgelogd en naar /login gestuurd. De controllers hoeven een 401 dus nooit zelf af te handelen.

Controller.php : 43

Zet een mislukte API-call om naar een redirect met een foutmelding.

public error(Response $response, string $default) : RedirectResponse

Bij 409 (naam bestaat al, of nog gekoppeld aan boeken) wordt de melding van de API getoond, anders de standaardmelding. Een 401 komt hier nooit aan: die wordt al door api() afgehandeld.
